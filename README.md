# Eorzea Toolkit

專為《最終幻想 XIV》（繁中服）玩家設計的輔助工具集，純 HTML 單檔實作，開啟即用，無需安裝。

> 作者自製自用，資料可能有誤，請斟酌參考。

---

## 工具總覽

### 製造成本計算機
計算生產物品的成本、稅後售價與時薪，幫助判斷製作是否划算。

- 輸入市場單價，自動計算稅後收入（支援 0% / 3% / 5% 交易稅）
- 自由新增多筆素材（名稱、單價、數量），一鍵算出素材總市價
- 水晶消耗單獨計算
- 選填食品費用，計入批量製作總成本
- 輸出：批量淨利、單件純利、製造時薪
- 若毛利為負，顯示虧損警示

### 任務提醒
追蹤每日與每週任務的完成進度。

- 初次使用時選擇習慣做的任務（每週、每日副本、採集 / 生產 / 其他）
- 打勾記錄完成狀況，進度條即時更新
- 可新增自訂任務
- 支援手動重置（日常 / 週常）
- 首頁顯示今日與本週任務未完成數量
- 設定與進度自動存入瀏覽器

### 潛水艇材料紀錄
選擇各部位規格，計算所需素材與目前缺口。

**部位選擇**：船體、船尾、船首、艦橋，各提供 10 種規格（鯊魚、甲鱟、鬚鯨、腔棘魚、希爾德拉，及其改造版本）

**素材清單**分三層顯示：
- 成品素材
- 半成品素材
- 基礎素材（考慮成品與半成品兩層抵扣）

每項素材可填入「已有數量」，自動計算還缺多少，並標示採購備註（商人價格、部族販售、潛水艇素材等）。

**共同編輯功能**：透過 Firebase Realtime Database 實現即時同步，適合多人共同規劃潛水艇配件。建立房間後分享 6 碼代號，加入後資料即時同步。

### 艾奧傑亞時鐘
即時顯示遊戲內時間（ET）、本地時間與伺服器時間。

**天氣預報**
- 支援全版本所有地圖（新生至黃金，共 60+ 個區域）
- 依地區分類切換，顯示未來 8 個天氣時段的天氣圖示與名稱
- 顯示目前天氣與距離下次變天的倒數

**限時採集節點**
- 收錄新生至黃金版本的珍稀節點
- 標示開放時段、區域、座標、職業（採礦師 / 園藝師）、是否為收藏品
- 依職業、版本、是否為收藏品篩選
- 標示「開放中」與「即將開放（20 分鐘內）」狀態，依時序排列

**特殊 FATE 一覧**
- 依版本（新生、蒼天、紅蓮、漆黑、曉月、黃金）分類
- 記錄 FATE 名稱、地點、對應成就、掉落物、觸發備註

### 海釣時間表
追蹤靛藍號的出發班次，規劃海釣行程。

- 顯示下次出發倒數，並列出靛藍與紅玉兩條航線的停靠站、時段與推薦用餌
- **班次時刻表**：列出近期 20 班，可依靛藍 / 紅玉篩選，標示「登船中」與「即將出發」
- **藍魚篩選**：依航線列出各藍魚的出沒地點、時段、特殊用餌、釣法，並顯示近期 5 個可釣班次

### 陸行鳥染色模擬
計算將陸行鳥染成目標顏色所需的果實順序。

**目標計算**：選擇目前顏色與目標顏色，自動計算需要哪些果實各幾顆，並列出逐步餵食順序與每步後的顏色變化。

**果實模擬**：從指定顏色出發，自行點選要餵食的果實種類與數量，模擬最終結果，並顯示對應最近似的命名顏色。

支援七種果實：塞爾法特爾沙果、輝鱗油梨、奧·哥摩羅漿果、多瑪青梅、瓦爾醋栗、謝爾達萊鳳梨、拉扎罕檸檬。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，或部署至任何靜態網頁服務（GitHub Pages、Cloudflare Pages 等）。

**資料儲存**：各工具的設定與進度存入瀏覽器 LocalStorage，更換裝置或瀏覽器時資料不會保留。潛水艇共編功能需要網路連線（Firebase）。

**深色模式**：點擊右上角 ☀ / ☽ 按鈕切換，偏好設定自動記憶。

## 技術說明

- 純 HTML + CSS + JavaScript 單檔實作，無任何前端框架依賴
- 字型：Cinzel（英文標題）、Noto Sans TC（中文）
- 潛水艇共編：[Firebase Realtime Database](https://firebase.google.com/)
- 天氣演算法：根據艾奧傑亞時間推算，與遊戲內機制一致
- 海釣班次：基於靛藍號固定 2 小時班次週期計算
